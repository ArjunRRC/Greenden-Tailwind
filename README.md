# GreenDen 🌿

GreenDen is a responsive artificial plants website built using only Tailwind CSS.  
This project features a clean and modern design for showcasing and selling artificial plants online.

## 🚀 Features

- Fully Responsive Design
- Modern UI with Tailwind CSS
- Attractive Landing Page
- Product Showcase Section
- Customer Review Section
- Contact Page
- Simple and Clean Layout

## 📄 Pages

- Home
- Products
- Contact

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS

## 🌱 Purpose of the Project

This project was created to practice frontend web development and improve Tailwind CSS skills by building a responsive multi-page website.# Greenden-Tailwind
